# ⚡ PlanTim - Quick Start Guide

**5-Minute Setup** - Od instalacije do prvog projekta!

---

## 🚀 Za Administratore - Instalacija i Pokretanje

### Korak 1: Instalacija (3-5 minuta)

1. **Pokreni MySQL** u XAMPP Control Panel
2. **Duplim klikom:** `SETUP_AUTO.bat`
3. **Sačekaj** da se završi instalacija

✅ Automatski instalirano:
- PHP paketi (Composer)
- Node.js paketi (NPM)
- Baza podataka `plantim`
- 40+ tabela
- Admin korisnici

---

### Korak 2: Pokretanje (30 sekundi)

**Duplim klikom:** `START_ALL_AUTO.bat`

✅ Pokreće:
- Backend server (port 8000)
- Frontend server (port 5173)

---

### Korak 3: Pristup (10 sekundi)

**Otvori browser:**
```
http://localhost:5173
```

**Login:**
```
Email:    admin@plantim.com
Password: password
```

**Gotovo! ✅**

---

## 🌐 Pristup sa Mobilnog/Drugih Računara

### Prvi Put - Setup (2 minute)

1. **Desni klik** → `COMPLETE_NETWORK_FIX.bat` → **Run as Administrator**
2. **Sačekaj** da završi

### Svaki Put - Pokretanje (30 sekundi)

1. **Duplim klikom:** `START_NETWORK.bat`
2. **Sa mobilnog:** `http://TVOJA_IP:5173`

**Login isti kao iznad!** ✅

---

## 🎯 Za Nove Korisnike - Prvi Koraci

### Korak 1: Pristup Sistemu (30 sekundi)

1. Otvori `http://localhost:5173`
2. Unesi email i password
3. Klikni **"Prijava"**

✅ Automatski si na Dashboard-u!

---

### Korak 2: Upoznaj Interfejs (1 minut)

**Sidebar (lijevo):**
- 📊 **Dashboard** - Početna stranica
- 👥 **CRM** - Upravljanje klijentima
- 📁 **Projekti** - Projektni menadžment
- 📄 **DMS** - Dokumenti i fajlovi
- 🎓 **LMS** - E-learning kursevi
- 👔 **HRM** - Ljudski resursi
- 💬 **Chat** - Interna komunikacija
- 🔔 **Notifikacije** - Obavještenja
- 🤖 **AI** - AI asistent
- ⚙️ **Admin** - Administracija

**Top Bar (gore):**
- 🔔 **Notifikacije** - Nova obavještenja
- 👤 **Profil** - Tvoj nalog
- 🌙 **Tema** - Light/Dark/Black
- 🌐 **Jezik** - Bosanski/English

---

### Korak 3: Kreiraj Prvi Projekat (2 minute)

1. **Klikni** na **"Projekti"** u sidebar-u
2. **Klikni** na **"+ Novi Projekat"** dugme
3. **Popuni formu:**
   - **Naziv:** "Moj Prvi Projekat"
   - **Opis:** "Ovo je test projekat"
   - **Status:** Active
   - **Prioritet:** Medium
   - **Start datum:** Danas
   - **End datum:** Za mjesec dana
4. **Klikni** **"Kreiraj"**

✅ **Projekat kreiran!**

---

### Korak 4: Dodaj Task (1 minut)

1. **Otvori** projekat koji si kreirao
2. **Klikni** **"+ Novi Zadatak"**
3. **Popuni:**
   - **Naziv:** "Moj prvi zadatak"
   - **Opis:** "Test zadatak"
   - **Status:** To Do
   - **Prioritet:** Medium
4. **Dodijeli:** sebi (tvoj nalog)
5. **Klikni** **"Kreiraj"**

✅ **Task kreiran!**

---

### Korak 5: Dodaj Kontakt u CRM (1 minut)

1. **Klikni** na **"CRM"** u sidebar-u
2. **Klikni** **"+ Novi Kontakt"**
3. **Popuni:**
   - **Ime:** "Marko"
   - **Prezime:** "Marković"
   - **Email:** "marko@example.com"
   - **Telefon:** "123-456-789"
   - **Kompanija:** "Test Kompanija"
4. **Klikni** **"Kreiraj"**

✅ **Kontakt dodat!**

---

### Korak 6: Upload Dokument (1 minut)

1. **Klikni** na **"DMS"** (Document Management)
2. **Klikni** **"Upload"** ili **drag & drop** fajl
3. **Izaberi fajl** sa računara
4. **Klikni** **"Upload"**

✅ **Dokument uploaded!**

---

**🎉 Gotovo! Uspješno si:**
- ✅ Kreirao projekat
- ✅ Dodao task
- ✅ Dodao kontakt
- ✅ Upload-ovao dokument

## 👥 Kreiranje Novog Korisnika (Admin)

### Korak 1: Idi u Admin Panel

1. **Klikni** na **"Admin"** u sidebar-u
2. **Klikni** na **"Users"**

### Korak 2: Dodaj Korisnika

1. **Klikni** **"+ Novi Korisnik"**
2. **Popuni:**
   - **Ime:** "Ime Prezime"
   - **Email:** "email@domena.com"
   - **Password:** Privremena lozinka
   - **Uloga:** Employee / Manager / Admin
   - **Status:** Active
3. **Klikni** **"Kreiraj"**

### Korak 3: Dodjeli Permisije

1. **Otvori** korisnika
2. **Klikni** **"Permissions"**
3. **Izaberi** module kojima može pristupiti:
   - ✅ Dashboard
   - ✅ Projects
   - ✅ CRM
   - ... itd
4. **Sačuvaj**

✅ **Korisnik kreiran!**

Novi korisnik se sada može prijaviti sa svojim kredencijalima!
